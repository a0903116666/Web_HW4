## 為什麼

這個專題需要一個小型全端網站，用來記錄與展示商品價格歷史，而且要容易展示、容易說明。我選擇維力炸醬麵，因為它是大家熟悉的商品，價格變化也很容易理解，方便呈現趨勢資料與截圖。

## 變更內容

- 新增一個以所選商品為主題的價格追蹤網站。
- 新增日期、商品名稱、商品價格的輸入表單。
- 新增簡單查詢功能，讓使用者可以縮小目前顯示的歷史資料範圍。
- 將提交的資料儲存在 SQLite 中，避免重新整理後資料消失。
- 以表格或清單方式顯示已儲存的資料，呈現價格隨時間的變化。
- 內建至少三筆範例資料，讓第一次展示就能看到變化。
- 為 GitHub 上傳與 HackMD / Notion 書面教學文件做好準備。
